### Pinch — AI Recipe Organizer
*Solo project · Full stack*

Mobile-first app that turns recipes from blogs and social media into structured, searchable data.

`React` `Sass` `Vitest` `Java` `Spring Boot` `Spring Security` `JWT` `PostgreSQL` `JUnit` `Mockito` `LLM API`

- Three import routes: JSON-LD parsing (schema.org/Recipe), AI-structured paste for sources like Instagram captions, and manual entry.

- Design system with semantic tokens, dark mode, AA contrast and ≥44px touch targets.
